# نظام إدارة الشرطة

لوحة جرد ومتابعة لأفراد القسم + بوت ديسكورد يقرأ الرتب والشهادات والتقارير تلقائياً.

---

## التشغيل

```bash
npm install
$env:BOT_TOKEN = "توكن_البوت"
$env:PORT = 3000
npm start
```

بعدها افتح `http://localhost:3000`

---

## متغيّرات البيئة

| المتغيّر | مطلوب؟ | 설명 |
|---|---|---|
| `BOT_TOKEN` | ✅ | توكن البوت من Discord Developer Portal |
| `GUILD_ID` | اختياري | آيدي سيرفر الشرطة (موجود بالإعدادات داخل `index.js`) |
| `ADMIN_IDS` | اختياري | كوبي آيات المشرفين، تفصل بفاصلة `,` |
| `PORT` | اختياري | المنفذ، افتراضياً `3000` |
| `REQUIRE_MEMBER_ROLE` | اختياري | `true` = لازم رتبة شرطة عشان يسجّل (افتراضياً `false`) |
| `DEFAULT_CAN_EDIT` | اختياري | `false` = الجديد يقدر يشوف بس ما يعدّل (افتراضياً يعدّل) |

### صلاحيات البوت في السيرفر

- `View Server` (أثال)
- `Read Message History` (رووم MDT / CADET / SOLO CADET / الساعات)
- `Send Messages` (اختياري)
- **`View Audit Log`** ← مهمة جداً، بدونها ما بيعرف مين أعطى الرتبة والشهادات
- `Presence Intent` من Developer Portal (مطلوب لجلب الأعضاء)

## كيف يشتغل

### الدخول والتسجيل
1. المستخدم يسجّل **مرة واحدة**: اسمه بالديسكورد + كوبي آي دي + اسم شخصيته + إيميله.
2. البوت يتحقق إن الآيدي **فعلاً موجود بسيرفر الشرطة** وإن الاسم يطابق — فما في تسجيل كاذب.
3. الطلب يروح بانتظار موافقة المشرف ← المشرف يوافق من تبويب **حسابات الموقع**.
4. بعدها يدخل مباشرة بالآيدي أو بكلمة السرّ — والموافقة محفوظة على السيرفر وما تضيع بعد إعادة التشغيل.
5. المشرف يقدر **يوقف** أي حساب (مع سبب يظهر له)، أو **يمسح تسجيله** خلنه يسجّل من جديد.

### المتواجدون
كل من يدخل اللوحة ينسجّل لحظياً: الوقت، الـ IP، الجهاز، **وشو الصفحة اللي يشوفها الحين**، وعدد مرات دخوله.
مبني على Socket.IO + نبضة كل ٢٥ ثانية، فيتشال تلقائياً إذا الاتصال طاح.

### سجل الخدمة (من Audit Log)
البوت يقرأ سجل ديسكورد الداخلي ويسجل لكل فرد:
- مين رقّاه ومتى (`MemberRoleUpdate`)
- مين أعطاه كل شهادة ومتى
- متى انضم للسيرفر (`MemberJoin`)

وتقدر تشوفه كلها بسجل زمني مرتب داخل ملف الفرد.

## الرتب

- **الترتيب** يجي من **موضع الروم بالديسكورد** تلقائياً (الأعلى = رتبة أعلى).
- تبي تغيره؟ تبويب **الرتب** (للمشرف): اسهم لأعلى/لتحت، زر قلم لتغيير الاسم، وزر عين لإخفاء رتبة من الجدول. ثم **حفظ الترتيب**.
- **أي رتبة جديدة تنشئها بالسيرفر تنكتب تلقائياً** ما تحتاج تعديل كود — يتعرف عليها，只要 اسمها فيه كلمة دالة على رتبة:
  `chief` `deputy` `captain` `lieutenant` `sergeant` `officer` `cadet` `corporal` `detective` `inspector` `marshal` `commander` `supervisor` `constable` `trooper` `agent` `sheriff` `patrolman` `recruit`
- **تغيير رتبة فرد**: من القائمة المنسدلة بعمود الرتبة بالجدول (أو من نافذة التعديل). يشيل رتبته القديمة ويضيف الجديدة **فعلياً بالديسكورد**، ويسجل السبب بالبروفايل.
- **الأكاديمية** (الكاديت + السولو كاديت) = آخر رتبتين بالترتيب.

> ⚠️ لتغيير الرتبة من الموقع يحتاج البوت:
> 1. صلاحية **Manage Roles**
> 2. رتبة البوت بالسيرفر تكون **أعلى** من الرتب اللي يغيّرها
>
> لو ما عنده، تظهر رسالة واضحة بالموقع بدل ما يصير شي بصمت.

## روم الخصم والنقاط والترقيات

البوت يقرأ القالب (Embed) ويستخرج المنشن والرقم والسبب ومن أمر.

**روم الخصم** — `Officer` + `strike`:
```
Officer : @mention
strike  : 20
Reason  : مخالفة مرورية
Commed By : @mention
```
→ **يُخصم 20 نقطة** من الجدول، وينسجّل بكل التفاصيل بالبروفايل، ويزيد عدّاد الاسترايك.

**روم النقاط** — `Officer` + `Points`:
```
Officer : @mention
Points  : +15
Reason  : أداء ممتاز
Commed By : @mention
```
→ **يُضاف 15 نقطة**. اكتب رقم سالب (`-20`) ويخصم بدل ما يضيف.

**روم الترقيات** — `Officer Name` + `From` + `To`:
```
Officer Name : @mention
From : Officer I
To   : Officer II
Reason : إنجاز في العمليات
Commed By : @mention
```
→ تنسجّل الترقية (من ← إلى + السبب + الأمر) ببروفايل الفرد وبسجل الخدمة.

**ملاحظات:**
- الأرقام تُقرأ من اسم الحقل، فما يتأثر على قيمة السبب اللي فيه أرقام.
- الرصيد **ما ينزل تحت الصفر**، والسجل يبيّن المقدار المطلوب مقابل اللي طُبّق.
- الحقول مو حساسة لحالة الأحرف وتقبل الأخطاء الإملائية (`Coommend` / `Commend`).
- أول ما السيرفر يشتغل يقرأ أرشيف الرومات الثلاثة، فما يفوتك شي قديم.
- الأسماء مو شرط تكون بالإنجليزي — اقرأ الاسم الحقيقي من الديسكورد ونسّقه (يشيل `★` والإيموجي).
